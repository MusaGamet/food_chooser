Food Chooser — How to run (enhanced)

Этот репозиторий — небольшой статический фронтенд с опциональным демонстрационным Node/Express backend для имитации аутентификации.

Запуск фронтенда

- Открыть `index.html` в браузере (подходит для базового просмотра).
- Рекомендую использовать Live Server или Python HTTP сервер:

```powershell
# Python
python -m http.server 8000
# или
py -3 -m http.server 8000
```

```powershell
# Node http-server (если установлен)
http-server -p 8080
```

Демонстрационный backend (Node/Express)

1) Установите зависимости (в папке проекта):

```powershell
npm install
```

2) Запустите сервер:

```powershell
npm start
```

Сервер по умолчанию открывает статику и API на http://localhost:3000.

Login API

- POST /api/login
  - Тело: { username, password }
  - Успешный ответ: { ok: true, user: { username } }
  - Неверные учётные данные: 401 { ok: false, error }

Тестовые учётные данные (в файле `data/users.json`):
- admin / admin123
- user / password

UX улучшения

- Кнопки удаления в корзине, кнопка "Очистить корзину".
- Улучшенный `login.html` с индикатором загрузки и отображением ошибок от backend.
- Авторизация с хранением пользователя в localStorage и возвратом на предыдущую страницу после логина.

Безопасность

Это демонстрация — не используйте подобный подход в production. Для реальной аутентификации нужно хранить пароли в хэшированном виде и проверять на сервере по защищённому соединению.

Если нужно, могу:
- Переписать backend с JWT и sqlite (или другим хранилищем).
- Подключить сборку (npm scripts) и dev workflow.
- Добавить инструкции по деплою.
